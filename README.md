# LocalAncestryInference_YeastAdmixture

> ⚠️ **Work in progress** — this repository is under active development.

Snakemake pipeline for local ancestry inference (LAI) in *Saccharomyces cerevisiae* multi-ancestry individuals, using RFMix, GNOMix, AncestryHMM, and consensus calling. Includes tract-based metrics computation &  visualization.

## Status

This pipeline is being developed as part of an M2 internship project in population genomics. Full documentation &  usage instructions will be added once pipeline reproducibility is ensured.
